# 队伍库

网页"打一场"页上每队旁边的"存进队伍库"把那一队存到这里，"从队伍库载入"从这里选一队填回去。一队一个 TOML 文件，文件名按队名（例如 `Team_A.toml`）。格式见 `pogo_sim/team_library.py` 开头：`league`（常用联盟，只用来筛选）、可选的 `custom_files`（这一队用到的覆盖文件，载入时自动勾上）和 `note`，然后是 `[team]`。`[team]` 和 3v3 配置里的一个 `[[team]]` 写法相同。

也可以手写文件放进来。读不了的文件会在网页的列表里单独列出原因。

网页不能删除这里的文件，要删就手动删。存的时候同名的文件已经有了，网页会先问再覆盖。这个目录入库，跟着备份到 GitHub。
